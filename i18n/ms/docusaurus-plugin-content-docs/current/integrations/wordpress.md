# WordPress

Gunakan plugin WordPress untuk menyegerakkan kenalan, menghantar notifikasi dan mengurus data pengguna melalui sambungan Wabot yang dibenarkan. Rujuk REST API atau OAuth/MCP untuk kredensial, simpan token dengan selamat, dan uji di laman staging sebelum menggunakan laman produksi.
