# Google Spreadsheets

Buka **Integrations → Google Spreadsheets → Settings** untuk menyemak atau menghubungkan konfigurasi helaian.

Gunakan integrasi ini dalam automasi atau chatbot untuk menambah baris baharu atau mengemas kini baris helaian. Uji dengan helaian dan data terkawal dahulu. Jangan tukar sambungan atau pemetaan lajur jika aliran produksi masih menggunakannya.
