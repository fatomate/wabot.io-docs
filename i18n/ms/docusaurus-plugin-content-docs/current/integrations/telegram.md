# Notifikasi Telegram

Dalam **Integrations → Telegram Notification → Settings**, konfigurasikan chat ID Telegram untuk menerima notifikasi peristiwa Wabot.

Gunakan chat ID berasingan untuk jenis makluman berbeza jika perlu. Uji penghantaran notifikasi dan jangan kongsi token bot atau chat ID operasi secara terbuka.
