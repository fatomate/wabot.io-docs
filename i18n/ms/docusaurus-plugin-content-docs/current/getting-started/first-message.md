# Hantar Mesej Pertama

Uji penghantaran dengan nombor terkawal selepas akaun bersambung. Gunakan Live Chat untuk mesej manual, Broadcast untuk kempen kecil, atau REST API untuk integrasi. Semak status penghantaran dan Account Error Logs jika mesej gagal.
