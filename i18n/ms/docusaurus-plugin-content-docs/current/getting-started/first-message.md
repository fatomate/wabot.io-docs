# Hantar Mesej Pertama

Uji penghantaran dengan nombor terkawal selepas akaun bersambung. Gunakan LiveChat untuk mesej manual, WhatsApp Blast untuk kempen kecil, atau REST API untuk integrasi. Semak status penghantaran dan Account Error Logs jika mesej gagal.
