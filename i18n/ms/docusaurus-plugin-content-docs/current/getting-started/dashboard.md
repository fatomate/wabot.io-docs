# Dashboard

Dashboard memaparkan pelan, kredit AI, Message Activity, Subscriber Growth, Subscriber Breakdown, akaun WhatsApp, aktiviti terkini dan **Full Analytics**.

Urutan persediaan dicadangkan: sambung akaun, sediakan Audience Hub, templat/media, chatbot atau Auto Reply, LiveChat, uji WhatsApp Blast kecil, kemudian automasi dan integrasi.
