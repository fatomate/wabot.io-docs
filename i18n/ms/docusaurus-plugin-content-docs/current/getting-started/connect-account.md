# Sambung Akaun WhatsApp

1. Buka **Accounts → Add Account**.
2. Pilih **Unofficial API** untuk sambungan QR/kod pasangan, atau **Official API** untuk sambungan Meta Business.
3. Lengkapkan langkah yang dipaparkan dan tunggu status **Connected**.
4. Buka akaun dalam **Accounts** untuk menyemak status, provider dan butiran sambungan.

Kad **WebChat** dalam Add Account kini dinyahaktifkan sebagai **Coming Soon**. Untuk widget web, sambungkan akaun dahulu, kemudian buka **Chatbots → [akaun] → Widget Setting**.

Anda memerlukan kebenaran menambah akaun untuk membuka aliran sambungan. Pilihan Unofficial API/QR disembunyikan jika ruang kerja tidak mempunyai akses Unofficial API.

Jangan kongsi token akses atau Instance ID.
