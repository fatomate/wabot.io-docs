# Urus Akaun

Dalam **Accounts**, guna Grid/Table view, carian, penapis, **Refresh data** dan **Settings**.

Jika Accounts memaparkan **Access Restricted**, minta pemilik ruang kerja memberikan akses akaun sebelum menyambung, mengedit atau memeriksa akaun.
Menambah atau mengurus akaun memerlukan kebenaran pengurusan akaun; pemadaman memerlukan kebenaran delete akaun yang berasingan.

Halaman akaun mempunyai tab **Overview**, **Settings** dan **Developers**. Overview menunjukkan status, provider, WABA, baki, skor kualiti, had mesej, LiveChat serta kredensial API yang disembunyikan.

Tindakan seperti **Disconnect**, **Switch to Unofficial** dan **Delete Account** boleh mengganggu WhatsApp Blast, automasi dan chatbot. Semak kerja bergantung dan eksport laporan penting sebelum meneruskannya.

Akaun Website boleh menunjukkan **Feature Under Development** untuk pengguna bukan admin. Akaun API Tidak Rasmi boleh menunjukkan **Unofficial API Unavailable** jika pelan tidak menyokongnya. Tab **Settings** dan **Developers** memerlukan akses tulis akaun.
