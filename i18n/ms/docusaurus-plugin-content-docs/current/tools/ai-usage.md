# Penggunaan Token AI

Dari **Chatbots**, klik **AI Token Usage** untuk menyemak kredit AI dan penggunaan permintaan.

1. Gunakan carian atau tapis mengikut **Type**, **Source**, **Instance**, atau **Tool Calls**.
2. Pilih julat tarikh.
3. Semak kredit tersedia, jumlah ditapis, dan pecahan penggunaan.
4. Klik **View Details** untuk maklumat token, kos atau kredit, dan panggilan alat bagi satu permintaan.

Penggunaan pembekal terurus boleh menggunakan kredit AI Wabot. Penggunaan BYOK direkodkan secara berasingan.
