# Penjana Pautan

Gunakan **Link Generator** untuk pautan WhatsApp klik-untuk-chat dan kod QR.

Jika anda melihat **Access Restricted**, minta pemilik menyemak pelan dan kebenaran Link Generator anda.

1. Pilih akaun atau **New Phone Number**.
2. Masukkan nombor yang sah dan mesej pra-isi jika diperlukan.
3. Salin pautan yang dijana.
4. Sesuaikan dan muat turun QR dengan warna, gaya titik/sudut, saiz atau imej tengah.

Pautan tidak disimpan sebagai rekod server. Semak nombor dan mesej sebelum menerbitkan QR.
