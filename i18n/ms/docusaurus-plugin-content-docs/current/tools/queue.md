# Mesej Queue

Gunakan **Queue Message** untuk menyemak mesej beratur, berjadual, dihantar atau gagal.

Memadam mesej queue atau mencuba semula mesej gagal memerlukan kebenaran delete Queue.

1. Tapis mengikut jenis akaun, akaun, status, tarikh dan penerima.
2. Klik **View details** untuk menyemak penerima, sumber dan ralat.
3. Pilih rekod yang betul.
4. Gunakan **Delete Selected Items** hanya untuk mesej yang tidak patut diproses.
5. Gunakan **Retry Selected Messages** hanya untuk mesej gagal selepas puncanya dibetulkan.
6. Muat semula Queue untuk mengesahkan hasil.

Memadam atau mencuba semula Queue tidak membetulkan siaran, automasi, chatbot atau permintaan API yang menciptanya. Tindakan bagi semua rekod ditapis memerlukan frasa pengesahan.
