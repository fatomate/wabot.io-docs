# Analitik

Gunakan **Full Analytics** untuk menyemak aktiviti mesej, WhatsApp Blast, chatbot, automasi dan pelanggan bagi akaun WhatsApp.

1. Dari Dashboard, klik **Full Analytics**.
2. Pilih akaun WhatsApp dan julat masa, seperti **Today**, **Last 7 Days**, **Last 30 Days**, **This Month**, atau **Custom Range**.
3. Semak KPI, garis masa mesej, hasil WhatsApp Blast, aktiviti chatbot dan automasi, serta pandangan pelanggan.
4. Klik **Refresh** untuk mendapatkan angka terkini.

Jika data tidak dimuatkan, gunakan **Try Again** dan pastikan akaun masih bersambung.
