# Log Ralat Akaun

**Account Error Logs** ialah halaman sokongan untuk pemilik pasukan.

1. Gunakan penapis **All instances** dan **All surfaces**.
2. Klik **Show details** untuk melihat butiran teknikal dengan selamat.
3. Klik **Refresh** untuk memuatkan data terkini.

**Delete selected** dan **Delete all filtered** memadam rekod secara kekal. Simpan butiran yang diperlukan untuk sokongan sebelum memadamkannya.
