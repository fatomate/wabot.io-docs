# Kapsyen

Gunakan **Caption** untuk menyimpan teks boleh guna semula.

1. Klik **New Caption** dan masukkan kandungan.
2. Gunakan **Preview** untuk menyemak paparan WhatsApp.
3. Klik **Copy** untuk menggunakan semula teks.
4. Gunakan **Edit** untuk mengemas kini kandungan.

**Delete** dan **Delete Selected** tidak boleh dipulihkan.
