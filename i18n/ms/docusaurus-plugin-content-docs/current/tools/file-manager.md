# Pengurus Fail

Gunakan **File Manager** untuk menyimpan dan menggunakan semula media.

Kebenaran fail adalah mengikut tindakan. Muat naik, cipta folder, namakan semula, pindahkan dan padam memerlukan akses masing-masing; pengguna baca sahaja hanya boleh menyemak kandungan yang dibenarkan untuk peranan mereka.

1. Cari atau tapis fail mengikut jenis.
2. Klik **Upload** untuk menambah fail atau **New Folder** untuk mengatur media.
3. Buka folder, gunakan grid atau senarai, dan klik ikon maklumat untuk pratonton butiran fail.
4. Gunakan tindakan fail untuk salin URL, ubah nama, pindah, edit kapsyen atau padam jika dibenarkan.

Jangan padam fail yang digunakan oleh siaran, chatbot, automasi atau templat aktif.
