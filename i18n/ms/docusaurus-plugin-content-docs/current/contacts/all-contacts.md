# Kenalan

Dalam **Audience Hub → People**, pilih **Contacts** atau **Subscribers**, pilih akaun, dan gunakan carian, penapis serta lajur untuk mencari orang.

Buka profil untuk menyemak nama, nombor, label, sejarah dan medan tersuai. Gunakan **Add Contact**, import atau eksport hanya selepas memilih akaun yang betul. Tindakan padam individu atau pukal adalah kekal.
