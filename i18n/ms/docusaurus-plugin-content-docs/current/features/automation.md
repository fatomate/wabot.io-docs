# Automasi

:::warning Ketersediaan V4 semasa
Halaman **Automation** V4 kini ditanda **Coming Soon**. Automasi V4 belum boleh dicipta atau diurus dari halaman ini.

Teruskan menjalankan automasi sedia ada dalam **V3** sehingga enjin automasi V4 dikeluarkan. Halaman V4 hanya memaparkan pratonton webhook triggers, label triggers, scheduled follow-ups, response logs dan tindakan aliran kerja.
:::

Apabila V4 tersedia, aliran persediaan yang dirancang ialah:

1. Buka **Automation → Create Automation**.
2. Masukkan nama, penerangan, jenis akaun, akaun WhatsApp dan status.
3. Pilih pencetus **Webhook** atau **Label**.
4. Untuk label, pilih **Label Added** atau **Label Removed**.
5. Pilih **Skip action with errors** atau **Stop automation on error**.
6. Klik **Create & Add Actions**, tambah tindakan, dan uji dengan kenalan atau payload terkawal.
7. Semak **Settings**, **Actions**, **Logs**, dan **Follow-ups** sebelum mengaktifkan automasi.

Gunakan **Retry** atau **Retry Failed** pada log gagal hanya selepas membetulkan punca. Automasi memerlukan akaun WhatsApp yang bersambung; akaun Website tidak disokong.
