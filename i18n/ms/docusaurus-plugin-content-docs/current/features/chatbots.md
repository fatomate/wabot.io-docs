# Chatbot

Buka **Chatbots** untuk mengurus chatbot bagi setiap akaun.

Pengguna yang mempunyai akses baca Chatbot tetapi tiada akses tulis boleh menyemak konfigurasi, tetapi tidak boleh mengubah AI knowledge, memory, tools atau tetapan.

1. Cari akaun dan semak status **Run Chatbot**.
2. Gunakan kawalan status untuk hidupkan atau hentikan pemprosesan chatbot bagi akaun itu.
3. Klik **Manage** atau **AI Settings** untuk konfigurasi AI.
4. Konfigurasikan persona, model, konteks, pengetahuan, memori dan alat mengikut kebenaran anda.
5. Uji dalam **AI Playground** sebelum mengaktifkan perubahan.

Halaman instance boleh menyediakan AI settings, knowledge dashboard, custom tools, widget settings, version management dan playground. Pulihkan versi atau gunakan templat chatbot hanya selepas menyemak kesannya, kerana penggunaan templat boleh menggantikan konfigurasi sedia ada.

Ketersediaan custom tools bergantung pada jenis alat, pelan dan kebenaran. Sesetengah alat boleh ditanda **Coming Soon**, dikunci pelan premium atau menunjukkan **Feature Under Development**.

Contohnya, alat Calendar ditanda **Coming Soon** sehingga akses Google Calendar diaktifkan untuk ruang kerja.

Widget web diterbitkan daripada tetapan chatbot akaun yang bersambung, bukan daripada kad WebChat dalam Add Account.
