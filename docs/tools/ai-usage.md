# AI Token Usage

Use **AI Token Usage** to review managed AI credits, BYOK activity, requests, and tool usage.

## Open AI Token Usage

From **Chatbots**, click **AI Token Usage**, or open:

`https://app.wabot.io/dashboard/ai-usage`

## Review Usage

1. Use search to find a request or related number.
2. Filter by **Type**, **Source**, **Instance**, or **Tool Calls**.
3. Choose a date preset or custom date range.
4. Review available credits, filtered totals, and spend breakdown.
5. Open **View Details** for the request-level token count, cost or credit information, tool calls, and available memory-operation metadata.

Managed-provider usage can consume Wabot AI credits. BYOK usage is recorded separately and is not charged against managed-provider credits in the same way.

Do not share request details that contain customer conversation content, phone numbers, or integration information outside the team that is authorized to access them.
