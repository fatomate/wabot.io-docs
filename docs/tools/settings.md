# Account Settings

Settings contains your personal profile, preferences, and security controls. Some tabs are only visible to the active team owner.

## Update Your Profile

1. Open **SUPPORT → Settings**.
2. Select **Profile**.
3. Update your name or username, and upload an avatar if needed.
4. Save the changes.

Your email is part of your account identity and may not be editable from this screen.

## Set Preferences

1. Select **Preferences**.
2. Choose your preferred language and timezone.
3. Save the changes.

Use the correct timezone before scheduling broadcasts or reviewing activity timestamps.

## Change Your Password

1. Select **Security**.
2. Enter the current password and a new password.
3. Save the change.
4. Sign in again on any device if prompted.

## Owner-Only Tabs

Team owners can also use:

| Tab | Purpose |
| --- | --- |
| **Notifications** | Configure owner-level notification preferences |
| **Purchase History** | Review subscription and purchase records |
| **Activity Log** | Review recorded actions for the active team |

For programmatic credentials, use **Tools → OAuth & MCP**, not the Profile tab.
