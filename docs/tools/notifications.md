# Notifications

Use Notifications to review operational alerts, team invitations, and linked conversation updates.

## Open Notifications

Click the bell icon in the dashboard header.

## Manage Alerts

1. Switch between **Inbox** and **Archived**.
2. Use search to find an alert.
3. Open an alert to see its details.
4. Use the available actions to mark it read, archive or unarchive it, or delete it.
5. Use **Mark all read** only after reviewing alerts that might require action.

Some notifications link directly to Live Chat. Open the linked conversation when you need the full message context.

## Notification Preferences

Open **Settings → Notifications** if you are a team owner. Available preferences can include alerts for:

- Instance disconnects or logouts
- Broadcast status
- Chatbot AI errors
- Delivery failures
- AI-credit events

Telegram notification configuration requires the appropriate integration permission. A partial-load warning means one notification source could not be loaded, not that all notifications are unavailable.
