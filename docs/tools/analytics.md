# Analytics

Use **Full Analytics** to review account activity across messages, broadcasts, chatbots, automations, and subscribers.

## Open Analytics

From the Dashboard, click **Full Analytics**, or open:

`https://app.wabot.io/dashboard/analytics`

## Review an Account

1. Select the WhatsApp account to analyse.
2. Choose **Today**, **Last 7 Days**, **Last 30 Days**, **This Month**, or **Custom Range**.
3. For a custom range, select both dates and apply the range.
4. Review the KPI summary, message timeline, broadcast results, chatbot and automation activity, and subscriber insights.
5. Click **Refresh** after a campaign or configuration change when you need current figures.

If the page cannot load the selected account's figures, use **Try Again**. Confirm that the account is connected before treating missing analytics as zero activity.

## Use Analytics Safely

- Compare the same date range and account before drawing a conclusion.
- Open the related Broadcast report, Automation logs, or Chatbot configuration before changing a live workflow.
- Analytics reflects available account data. It is not evidence that recipients opted in or that an outbound message was compliant.
